# 角色卡说明

`characters/*.json` 是角色卡来源。后端启动时会读取这些文件，并把角色信息 upsert 到 SQLite。

## 角色卡内容

角色卡主要包含：

- 基础身份和人设。
- 题材类型：`setting_type` 和 `setting_notes`。
- 场景设定。
- 示例语气。
- 行为策略。
- 禁止模式。
- 语音风格和背景。

## 修改原则

- 修改角色卡后重启后端即可重新同步。
- 角色卡负责稳定人设，不负责固定每轮动作。
- 校园轻伴是 `setting_type=campus` 的模板类型，不是所有角色的默认世界观。
- 动态动作密度、提问方式、记忆方式等策略可以通过角色卡配置，但具体输出仍由上下文和 LLM 决定。
